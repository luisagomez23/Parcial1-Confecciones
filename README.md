# Parcial 1 - Liquidación del taller de confección

Programación III - Universidad del Quindío

Integrantes: Luisa María Gómez Gómez, Juan Camilo Gordillo, Juan Esteban Mejia

## Compilación y ejecución

```bash
elixirc datos.exs util.exs validacion.exs liquidacion.exs reportes.exs
elixir programa.exs
```

## Módulos

- `Datos`: datos del taller 
- `Util`: funciones de apoyo
- `Validacion`: reglas de validación de lotes
- `Liquidacion`: valor de lotes, bonificación, alquiler y neto
- `Reportes`: reportes 
- `Programa`: función main
